
# Rectangle DIV Animation


This is a basic animation using a single <div>.
The <div> moves along the X-axis based on the mouse cursor’s movement.

However, there are some restrictions. In certain areas on the left and right sides of the screen, the mouse continues to move but the <div> does not respond. As a result, the <div> moves only within a limited range of the screen.

## GSAP

a powerful, high-performance JavaScript library for creating complex, smooth, and fast animations on the web
